# v0.2.0 entegrasyon durumu

Tarih: 24 Ekim 2026. Çalışma dalı: `integration/v0.2.0`. Durum: **yerel yazılım entegrasyon adayı; yayın yapılmadı**.

## Sonuç

AI dalındaki 148 değişen dosyanın tamamı sınıflandırıldı. Uygun modüller ham aktarım ve düzeltme commit’leriyle alındı. Önceden tamamlanan reçete/karar düzeltmeleri korundu. Bu sürüm; reçeteye dayalı karar, manuel/model/simülasyon ayrımı, ürün takibi, mantıksal ayırma, kalıcı inceleme, veri toplama ve detection eğitim hazırlığı sunar.

Bu çalışma gerçek eğitilmiş model başarısını, kamera renk/PSRAM kararlılığını veya fiziksel ayırmayı doğrulamaz. Ana mimari dönüşümü v0.3.0 kapsamındadır. Kayıtların, mevcut kullanıcı dosyalarının veya eski ürün verilerinin silinmesi için işlem yapılmadı. Gerçek çalışma veritabanına migration uygulanmadı; migration testleri izole PostgreSQL konteynerlerinde çalıştı.

## Son kapsam kararı

Entegrasyon main’e squash ile alınacak; sürüm etiketi veya release oluşturulmayacak. Ayrıntılı integration geçmişi korunacak. AI dalı yerelde silinecek, arşiv dalı oluşturulmayacak. Özgün AI geçmişini saklama zorunluluğundan bilinçli olarak vazgeçildi. Önceki erteleme dalı silindi; aşağıdaki Git bilgileri entegrasyon sırasındaki tarihsel kayıttır.

İki Python yardımcısının işlevi API yönetimindeki akışlarla karşılandığı için eski dosyalardan vazgeçildi. Classification ve segmentation ayar taslakları saklanmayacak; ihtiyaç olduğunda uçtan uca özellik olarak geliştirilecek. Diğer ertelenen işler ve kabul ölçütleri [gelecek kapsam belgesinde](docs/v0.2.0-deferred-scope.md) korunur. Donanım, gerçek model ve tüm Docker servisleriyle doğrulama sınırları devam eder.

## Tamamlanan davranışlar

### API, sözleşmeler ve kalıcı kayıt

- Karar kısıtları ve güvenli hedef seçimi korundu. Ortak 19 JSON senaryosunda beklenen karar gerekçeleri hem C# hem Python tarafından doğrulanıyor.
- Takip zamanının geriye gitmesi, geçersiz geçişler, sonsuz/geçersiz ayırma süreleri ve büyük sayaçlarda taşma engelleniyor. Fiziksel aktüatör komutu üretilmiyor.
- Kalibrasyonda açık null bölümler, sonlu olmayan sayılar ve desteklenmeyen fiziksel aktüasyon reddediliyor. Ölçek ölçümü kaynak görüntü boyutuyla eşleştiriliyor.
- Yeni platform migration’ı eklemelidir. Ek migration tek ACTIVE dataset oturumunu koruyan kısmi unique indeks ekler. Mevcut ürün tablolarını yeniden oluşturmaz.
- Reçete/kalibrasyon aktivasyonu ve ilgili yazmalar transaction/advisory lock ile sıralanıyor. Aktivasyonun ikinci adımında hata verilmesi ve eşzamanlı aktivasyon test edildi. Yinelenen adlar kontrollü conflict olur.
- `POST /api/inspections/vision` Operator yetkisi ister. İstek UUID’si kalıcı inceleme kimliğidir; başarıdan sonraki tekrar aynı kaydı döndürür. API’nin gerçek Vision HTTP sunucusuyla bağlantısı test edildi; kamera ve model bu testte sahtedir.
- Reçete revizyonu ve seçilen kalibrasyon kimliği/sürümü sabitlenir; değişmiş yapılandırmayla sonuç kaydedilmez. Sonuç JSON’unda kalibrasyon kimliği/sürümü ve gözlem kaynağı korunur.
- Manuel gözlemde uydurma model adı, model sürümü ve inference süresi yoktur. Fotoğraf zamanı UTC’ye çevrilir. Simülasyon gerçek üretim KPI’larına dahil edilmez.

### Kamera ve Vision

- ESP32 uzun süreli yayın sunucusu port 81’de; still/raw/status kontrol sunucusu port 80’dedir. Kamera mutex’i sensör yeniden başlatma ve kare sahipliğini korur.
- Dashboard ikinci ESP32 stream bağlantısı açmaz; `GET /api/camera/preview` üzerinden Vision’ın bellekteki önizlemesini alır.
- Raw/JPEG fallback tek fotoğraf bütçesini paylaşır. Varsayılan still bütçesi 30 saniye, API bütçesi 35 saniyedir; timeout/unreachable kontrollü 504/503 üretir. API testi 3,2 saniyelik sahte still ile de başarılıdır.
- Servis anahtarı, 64 KiB istek sınırı, sınırlı HTTP iş parçacıkları, fotoğraf/inference eşzamanlılık kontrolü ve kamera yanıt boyutu sınırı eklendi. Geliştirme portu loopback’e bağlıdır.
- Sınıf sırası, model sürümü, input boyutu, detection görevi, artifact adı ve checksum sözleşmesi doğrulanır. Reçete değişikliği çalışan modelin etiketlerini değiştirmez. Dosya değiştirme restart gerektirir. Bu kontrol metadata/checksum ön kontrolüdür; gerçek model çalışma doğrulaması ayrıca gerekir.
- JPEG fallback model ve renk analizi için piksele çözülür. Renk analizi genel reçete ROI’sini kullanır; çok ürünlü veya kutu başına ayrı analiz iddiası yoktur.
- Süresi geçmiş API reçete cache’i sessizce canlı kaynak sayılmaz. Dosya fallback’i yerel tanı içindir; kalıcı API incelemesi açık snapshot taşır.
- Normal firmware’de HTTP throughput uçları kayıt edilmez. TCP tanısı varsayılan kapalı kalır.

### Dataset ve eğitim

- Start/import/camera yolları aynı reçete etiket doğrulamasından geçer. Interval zorunludur; gerçek hardware-trigger modu reddedilir. Görüntü gerçek decoder ile açılır; sahte JPEG başlığı geçerli görüntü sayılmaz.
- Yazmalar aynı kilit ve transaction kapsamında yapılır. Manifest atomik değiştirilir; normal yazma/DB hatasında yeni dosyalar ve manifest geri alınır. Hata enjeksiyonu testi eklendi.
- Başlangıç uzlaştırması manifesti esas alır. Kabul edilmiş görüntü kayıpsa oturum `RECOVERY_REQUIRED` olur; diğer API işlevleri çalışmaya devam eder. Mevcut notlar korunur. Depolama erişilemezse hata loglanır; API’nin diğer işlevleri açılabilir.
- Bu düzen tek API instance içindir; dağıtık filesystem/veritabanı atomik commit garantisi değildir. DB ve dataset volume birlikte yedeklenmelidir. Bilinmeyen/eski klasörler otomatik silinmez.
- Reddedilmiş kayıtlar eğitim/doğrulama/sayımdan çıkarılır. Hash uyuşmazlığı reddedilir; aynı görüntü farklı split’lere dağılmaz. Hatalı export çıkış kodu 2’dir. Çıktı klasörünün boş olması gerekir.
- Notebook’lar ortak export girişini kullanır. ONNX/PT/OpenVINO için sınıf sırası, sürüm ve dosya checksum’u taşıyan sidecar üretilir. `--model-version` ile sürüm verilebilir. Eğitim veya GPU benchmark çalıştırılmadı.

### Dashboard ve dağıtım

- API üzerinden Vision tetiklemesi ve manuel gözlem ayrı işlemlerdir. Yeniden denemede istek UUID’si korunur.
- Canlı önizleme üzerine başka zamandaki inceleme kutuları çizilmez. Sonuç ayrıntıları ayrı gösterilir; aynı snapshot üzerinde kutu gösterimi sonraya bırakıldı. Önizleme üzerinde yalnız reçete ROI’si kullanılabilir.
- Yeni sunucu yanıtı yerel iyimser dataset durumunun yerini alır. Uzaktan durdurulan oturum ve polling hatasında çekim devre dışı kalır. Gizlenen sayfa/offline olayı interval çekimini durdurur; açık bir yeniden başlatma gerekir.
- Gerçek KPI ayrımı, polling hataları ve gerçek SignalR bağlantı durumu görünürdür. Üretimde simülasyon kapalıysa simülasyon işlemleri etkin değildir.
- Compose servis anahtarını, süreleri, kamera override’ını ve read-only model volume’ünü geçirir. CI integration dalları ve manuel tetikleme için yapılandırıldı; görüntü test bağımlılıkları eklenir.
- Testcontainers ve Dashboard lock bağımlılıkları güncellendi. Eklenen .NET görüntü decoder’ı SkiaSharp’tır; Linux native asset paketi de eklenmiştir.
